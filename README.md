<p align="left">
  Kendi geliştirdiğim <b>FPD</b>, gerçek tarayıcı verilerini analiz ederek web uygulamalarındaki performans sorunlarını
  yalnızca listelemekle kalmayan; olası <b>root cause</b> (kök neden) ve <b>source code correlation</b>
  (kaynak kod eşleştirmesi) üzerinden nereden başlanması gerektiğini gösteren, npm'de yayımlanmış bir CLI aracıdır.
</p>

- 🔎 **Real Browser Analysis:** Playwright ile ağ istekleri, asset boyutları, caching ve render-blocking kaynakları inceler.
- 🎯 **Root Cause & Priority:** Bulguları önem, öncelik ve güven düzeyine göre sınıflandırır; olası kök nedenleri öne çıkarır.
- 🧩 **Framework-Aware Debugging:** React, Next.js, Angular, Vue ve diğer framework'leri tanır; uygun durumlarda bulguları proje dosyalarıyla eşleştirir.
- 📦 **Developer-Friendly CLI:** Terminal, JSON ve Markdown çıktıları sunar; yerel projeler ve canlı URL'lerle çalışır.

**Quick Start**

```bash
npm install @umutdev/fpd-cli
npx playwright install chromium
fpd analyze http://localhost:3000 --project . --verbose
```
